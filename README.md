# SMART-MED

A healthcare telemedicine platform — doctor appointment booking and video
consultation — built with role-based flows for patients, doctors, and admins.

```
smart-med/
  frontend/   React + Vite + Tailwind CSS frontend (mock data, no backend calls)
  backend/    Reserved for a future API implementation
```

## Frontend

See [`frontend/README.md`](./frontend/README.md) for setup instructions, demo
login credentials, and an overview of the folder structure.

## Backend

Not part of the current build. See [`backend/README.md`](./backend/README.md).
